#+TITLE: Squi
#+AUTHOR: Mathieu Marques

Personal World of Warcraft interface addon named after Squee, the goblin;
because it rhymes.

It is not distributed: the repository is linked straight into my game files.
Tested on my machine and my machine only, adjust your expectations.

* Installation

The game loads addons from =<root>/<flavor>/Interface/AddOns=. Link the
repository there instead of copying it. The link name must match the addon's
=.toc= file name.

#+BEGIN_SRC sh :results silent
ROOT="$HOME/Games/battlenet/drive_c/Program Files (x86)/World of Warcraft"
FLAVOR="_forever_"
ln -fns "$PWD" "$ROOT/$FLAVOR/Interface/AddOns/Squi"
#+END_SRC

Wine resolves symbolic links that point outside the prefix, so the repository
can live anywhere on the host filesystem.

* Dependencies

** Retrieve the Current Interface Number

#+BEGIN_SRC sh :results silent
ROOT="$HOME/Games/battlenet/drive_c/Program Files (x86)/World of Warcraft"
COLUMN='NR == 1 {
  for (i = 1; i <= NF; i++) {
    if ($i ~ /^Version!/) version = i
    if ($i ~ /^Product!/) product = i
  }
  next
}'
NUMBER='{
  split($version, v, ".")
  printf "%s:%d ", $product, v[1] * 10000 + v[2] * 100 + v[3]
}'
awk -F '|' "$COLUMN $NUMBER" "$ROOT/.build.info"
#+END_SRC
